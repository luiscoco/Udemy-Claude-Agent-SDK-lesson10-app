01

model

Alias or full ID; this lab pins three IDs. Aliases such as haiku, sonnet and opus move over time. Newer deck examples are not promises of account access.

02

fallbackModel

A distinct backup, or a supported comma-separated chain. The app exposes one backup. Overload handling and primary retry are documented behavior, not induced here.

03

effort

The SDK type supports low, medium, high, xhigh and max. Model support varies. This UI limits Sonnet/Opus to low, medium and high; pinned Haiku omits effort.

04

thinking

adaptive, enabled with budgetTokens, or disabled. This app uses adaptive with display omitted or disabled. Summarized display is a supported public summary where available, never raw private reasoning.

05

env

TypeScript replaces the subprocess environment; spread process.env. Python merges explicit values over inheritance. This app executes only TypeScript.

06

cwd / additionalDirectories

cwd picks the project for a new session. Additional directories add file access, not their settings. This lab sets settingSources to [] and does not demonstrate configuration discovery.

07

Not a latency guarantee

Effort and model choices can affect cost and response behavior, but provider load, caching and task variation matter. These small observations do not establish a universal ranking.
