01

Select a model

Compare the same small task with pinned Haiku, Sonnet and Opus IDs. Inspect the model on actual assistant messages. Aliases can move over time; account and provider access differ.

02

Configure a backup honestly

Pass a distinct fallbackModel and inspect the option. A healthy request does not demonstrate overload, fallback activation or a return to the primary.

03

Separate effort and thinking

Use supported effort levels separately from adaptive or disabled thinking. This lab omits thinking text and counts only returned thinking blocks. A zero count does not prove that no internal reasoning happened.

04

Preserve the subprocess environment

Spread process.env in TypeScript, then add a harmless classroom value. Observe that value and cwd from an actual guarded Node command without displaying keys.

05

Choose the correct project

Start a new query in Alpha or Beta. Confirm its marker and actual process cwd. Additional directories grant file access, not configuration loading.

06

Compare observations

Record actual cost estimates, elapsed time, model IDs and results. One small sample is a classroom observation, not a model-quality or speed benchmark.
