    Scope of the experiment

    Real SDK queries demonstrate pinned models, supported effort/thinking configurations, subprocess environment inheritance, separate cwd values and an extra shared-directory read. Fallback is configured but no provider outage is manufactured. Alias tables, fallback chains, summarized thinking, fixed thinking budgets and Python mappings are reference material. Filesystem settings are disabled explicitly. Application guards are not an operating-system sandbox. The SDK cost threshold is not an exact billing guarantee.
