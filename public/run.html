Configure and run the application.

Follow the same task across models, reasoning settings and classroom directories.

01

Check prerequisites

Use Node.js 24+, npm, an Anthropic key and access to the model you select. Keep optional npm dependencies enabled. Python is not needed to run this TypeScript app.

02

Install, configure and start

From presentations, run these commands. Preserve an existing .env. Enter your own key locally; never commit the real file. npm start explicitly loads the optional file. Shell variables take precedence.

cd .\agent-sdk\lesson10-models-environment
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
npm start
# http://127.0.0.1:3110
ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3110
03

Run Sonnet in Alpha

Keep the default Sonnet, low effort, adaptive thinking and Alpha project. Run once. Check ALPHA-10, the actual assistant model and the PostToolUse context probe showing lesson10-alpha and a verified cwd.

04

Compare models carefully

Choose pinned Haiku; the page selects disabled thinking automatically and the host omits effort for that example. Repeat the task. Try Opus with disabled or adaptive thinking. Compare actual IDs, estimates and elapsed times; do not treat this tiny exercise as a benchmark.

05

Change effort and thinking

Repeat with Sonnet medium effort and disabled thinking. Inspect the actual options. Thinking text remains omitted; returned block counts are metadata, not a window into hidden reasoning. Model/provider support varies.

06

Switch cwd and add a directory

Choose Beta and enable shared reference. Run a fresh query. Confirm BETA-10, lesson10-beta, verified cwd and SHARED-10 from an actual reference read. The extra directory grants access, not its settings.

07

Configure a distinct fallback

Choose Sonnet with Opus as backup. Inspect fallbackModel and the model on actual messages. A healthy run usually stays on the primary. No automatic failover is claimed unless actual runtime evidence shows it. Invalid IDs and authentication errors are not a reliable overload exercise.

08

Run from the terminal and troubleshoot

The sample indexes are 0=Haiku, 1=Sonnet, 2=Opus. sample:env loads .env; sample uses the same shell environment. Keep this terminal open for the server. Ctrl+C stops it. For Windows, configure the real Git Bash path if requested. Another listener needs a different PORT. Provider errors remain actual failures; no saved answers are substituted.

npm run sample:env -- 1
npm run sample:env -- 0
npm run sample:env -- 2
npm test
